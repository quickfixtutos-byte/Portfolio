Serverless to-do API

A secured REST API and a small web app on AWS, with no servers to manage. Users sign in, then create, read, update and delete their own tasks.

API GatewayLambda (Python)DynamoDBCognitoWAFX-RayS3Terraform
  • REST API on API Gateway with five CRUD routes. Each route calls its own Python Lambda function, under a least-privilege IAM role.
  • Cognito user pool authorizer protects every route. The static frontend (HTML, CSS, JavaScript) handles login and calls the API with CORS enabled.
  • DynamoDB single-table design with partition and sort keys, one global secondary index and streams enabled.
  • WAF and API Gateway caching switch on from Terraform variables. I confirmed cache hits and misses in CloudWatch metrics and used X-Ray to trace requests.

What went wrong. AWS account verification blocked the CloudFront distribution I had designed, and the support case stayed open past my deadline. I served the frontend from S3 static website hosting instead and documented the change in the README.
